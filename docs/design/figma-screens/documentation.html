DevOrbit documentation

A concise guide to the product architecture, connection methods, and honest data states in this build.

Getting started

Create an account, finish the optional onboarding flow, and open Command Center.

Integration methods

GitHub uses OAuth when configured. Codeforces uses username verification and public APIs. LeetCode uses an extension or import. Ollama is a local service.

Data principles

DevOrbit displays connected or user-created data only. Empty modules stay empty until a source is available.

Local AI

Install and run Ollama, configure the local server URL, verify the health check, and select an available model.

Problem imports

CSV and JSON imports should be previewed, mapped, checked for duplicates, and confirmed before records are created.

Privacy controls

Connections are explicit. Imports, exports, permissions, and deletion remain user-controlled.

Implementation status

Email delivery, third-party OAuth credentials, repository indexing, browser capture, and local-model health checks require environment-specific setup before their actions can be enabled.
